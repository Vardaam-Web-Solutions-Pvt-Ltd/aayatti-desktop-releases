# Releases

Installers are attached to each release on the
[Releases](https://github.com/Vardaam-Web-Solutions-Pvt-Ltd/aayatti-desktop-releases/releases)
page, not stored in this folder.

- Tags follow semantic versioning: `v1.0.0`, `v1.0.1`, `v1.1.0`.
- The tag matches the version shown in the app.
- Each release has a `checksums.txt` file with the SHA-256 hash of every
  installer.
- Releases marked **Pre-release** are test builds. Use the release marked
  **Latest** unless your IT team tells you otherwise.
