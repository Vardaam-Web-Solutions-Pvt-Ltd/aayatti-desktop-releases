# About releases

Installers are attached to each release on the [Releases](../../../releases)
page, not stored in this folder.

- Versions follow semantic versioning: `v1.0.0`, `v1.0.1`, `v1.1.0`. The
  version matches the one shown in the app.
- Releases marked **Pre-release** are test builds for pilot users, not yet
  code-signed. Use them only if your administrator asked you to.
- Each release has `Aayatti-Desktop-Companion_<version>_checksums.txt` with
  the SHA-256 hash of every installer. See "Check your download" in the
  [installation guide](../INSTALLATION.md).
- What changed in each version: [What's new](../WHATS-NEW.md).
